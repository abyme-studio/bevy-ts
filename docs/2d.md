# 2D

Bevy 0.20's 2D in TSX: a `Camera2d`, flat meshes and their `ColorMaterial`, sprites, and picking.
Rust components keep their Rust field names (`<Sprite custom_size>`); intrinsics take camelCase
props, as `<mesh>` does. `examples/shapes-2d` shows each working row; 2D does not show in the
editor's 3D view, so run it with play.

```tsx
<>
  <entity><Camera2d /></entity>
  <entity>
    <Transform translation={[-150, 0, 0]} />
    <mesh2d shape="circle" radius={50} />
    <material2d color="#f80" alpha={0.8} />
  </entity>
  <entity>
    <Sprite image="hero.png" flip_x />
  </entity>
</>
```

## `<mesh2d>` and `<material2d>`

`<mesh2d shape>` builds a `Mesh2d` from one of `<mesh>`'s 2D shapes (`circle`, `circularSector`,
`circularSegment`, `ellipse`, `annulus`, `rectangle`, `rhombus`, `regularPolygon`, `triangle2d`,
`capsule2d`, `convexPolygon`), with the same props and checks ([meshes.md](meshes.md)). It is flat
in the XY plane facing +Z, so it takes no `depth` or `segments`. Equal props share one mesh asset,
also with a `<mesh>` of the same shape. `color` is a shorthand for `<material2d color>`.

`<material2d>` is a `ColorMaterial`:

| prop | Bevy | |
|---|---|---|
| `color` | `color` | any colour form; default white |
| `alpha` | the colour's alpha | 0 to 1 |
| `alphaMode` | `alpha_mode: AlphaMode2d` | `"opaque"`, `"blend"` or `{ mask: n }`; unset, `"blend"` below alpha 1, else `"opaque"` |
| `texture` | `texture` | an asset path |
| `uvTransform` | `uv_transform` | `{ scale?, rotation?, translation? }`, as on `<material>` |

Equal props share one material. Props cannot be bindings. Bevy keeps 2D and 3D apart, so
`<mesh2d>` pairs with `<material2d>` and `<mesh>` with `<material>`: mixing them on one entity
fails the load at the element. The code is `crates/bevy-ts-tsx/src/intrinsics.rs`; the types are
`Mesh2dProps` and `Material2dProps` in `bevy-ts/jsx-runtime`.
