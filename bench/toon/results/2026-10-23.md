# 100 skinned foxes: pbr vs toon vs toon+ink

`crates/bevy-ts-material/tests/toon_bench.rs` (process `toon-bench`), release, Apple M5 Max,
1920x1080 offscreen, 100 animated `Fox.glb` in a 10x10 grid, one shadowed sun (one cascade), an
orthographic camera. 600 frames after 300 of warm-up; wall time per `app.update()`. Load average
19-39 during the run (a busy machine), so read the gaps, not the absolute numbers.

| arm | mean | p95 |
|---|---|---|
| pbr: the glTF's `StandardMaterial` | 3.51 ms | 4.14 ms |
| toon: script material on every fox and the ground, shadows, no prepass | 4.21 ms | 5.24 ms |
| toon + ink: plus `DepthPrepass` and `NormalPrepass`, read for ink | 4.53 ms | 5.34 ms |

The prepass and ink cost about 0.3 ms per frame for 100 skinned characters. Toon over PBR is
about 0.7 ms here, with the same shadow pass in both.

`2026-10-23-loaded.md` is an earlier run at load 34-45, kept as the noise it was.
